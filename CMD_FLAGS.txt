# Flags added to every launch of Video Trim, so you do not have to type them
# each time. One per line; blank lines and #comments are ignored.
#
# NEVER put a password in this file. It sits here in plain text, and Video Trim
# deliberately does not read credentials from it. Set the login with:
#     python one_click.py --change-auth
#
# You should not need anything in here. With no flags the app serves on port
# 7862 on every interface, so it is reachable both at http://127.0.0.1:7862 on
# this machine and at http://<this-machine's-address>:7862 from your phone or
# another computer on the same network — the launcher prints both. That port is
# reserved for it: if something else already has 7862 the launcher stops with an
# explanation rather than quietly moving to another one.
#
# Everyone who opens it has to sign in. A device on another address can sign in
# but cannot make this machine write anything until you allow that address in
# Settings, on this machine. Reading files by path is a separate permission
# again, and is off for other machines unless you pass --allow-remote-files.
#
# Available flags:
#
#   --local-only             the opposite of the default: bind 127.0.0.1 only,
#                            so nothing outside this machine can reach the app
#   --listen-port 7862       serve on a different port
#   --listen-host 192.168.1.5   bind one specific interface
#   --output-dir <folder>    where saved clips and stills are created. Must
#                            already exist and must sit outside this
#                            installation. Stored, so it is only needed once —
#                            Settings can change it later.
#   --share                  also expose a temporary public gradio.live URL.
#                            Host Settings are hidden while a tunnel is up,
#                            because tunnelled traffic cannot be told apart
#                            from this machine's own.
#   --no-browser             do not open a browser window on start
#   --any-port               use the next free port instead of stopping when
#                            the chosen one is busy
#   --allow-remote-files     also let signed-in visitors from other machines
#                            browse and open paths on THIS machine. Grants
#                            reading only — never Settings, credentials, the
#                            save location, or write permission.
#   --proxy-height 720       height of the preview transcoded for codecs the
#                            browser cannot play natively
#
# Example — keep it to this machine only:
# --local-only
